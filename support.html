NostalgOS Support

NostalgOS is a handheld cartridge-file player for iPhone and Mac. It includes the original Pocket Demo, which you can play without importing a file. It does not supply commercial games or links to game downloads.

Add a cartridge

  • iPhone: Tap Import Cartridge on the empty player, or use + in Library. Choose a .gb, .gbc, .gba, or .zip file, or import a folder from Files. You can also open a supported file from Files into NostalgOS.
  • Mac: Choose File → Add Games… (Command–O), drop files or folders on the window or the Dock icon, or use Open With → NostalgOS in Finder.

Import files you have the right to use. NostalgOS copies imported cartridges into its local library. A .nostalgos file is a NostalgOS backup, not a cartridge.

ROM hacks and translations shared as .ips, .ups or .bps patches import the same way and become games of their own, with separate saves; the original is untouched. A UPS or BPS patch finds its game by checksum. An IPS patch needs its game alongside it with the same name (Game.gb and Game.ips); a single patch that can’t be matched asks which game it is for.

Try the built-in demo

On the empty library screen, choose Try Built-In Demo. Pocket Demo shows a moving pattern: use the D-pad to scroll it and hold A to change its colors. It is original content created for NostalgOS and can test controls, saves, and the display without another game file.

Saves, backups, and sync

Battery saves are written as you play. Quick Save keeps an exact place separately from a game’s own battery save. When you stop playing, NostalgOS also keeps a Where You Left Off state. Numbered save-state slots and rewind require NostalgOS Pro.

On iPhone, open Library → … for Back Up Library, Back Up Saves Only, or Restore from Backup. On Mac, use the File menu. A full library backup includes cartridge files; a saves-only backup does not. Keep a copy of any backup before replacing or deleting local data.

With NostalgOS Pro, saves sync through iCloud automatically; turn iCloud Sync off in Settings, or choose a custom folder under Advanced. Saves, save states and library details sync; ROM files stay on the device where you imported them. If a sync would delete many saves at once (for example after a library was emptied), it stops and changes nothing until you choose Delete Them Everywhere in Settings. Every save that sync deletes is kept on the device for 30 days.

To move a game’s own save to or from another emulator, use Export Save File… and Import Save File… in Save States on iPhone, or Game → Export Battery Save… and Import Battery Save… on Mac. The save being replaced is kept as a backup.

Advance cartridges and controllers

.gba files use the mGBA emulation core and L/R shoulder controls. No BIOS file is needed. Link cable, rumble, solar sensor, and gyro behavior are not fully emulated. NostalgOS supports compatible controllers recognized by Apple’s Game Controller framework; available buttons depend on the controller and system version.

Pro purchase and restoration

NostalgOS Pro is a one-time, non-consumable in-app purchase. It adds save sync, rewind, numbered save-state slots, faster and slower playback, palettes, screen effects, and extra shells. The core player and Pocket Demo are free. Pro can be shared with your family through Family Sharing. Open Settings → NostalgOS Pro → Restore Purchases if a purchase is missing on a device signed in to the same Apple Account. If the App Store cannot load the product, check the device’s connection and try again later.

Privacy and help

Read the Privacy Policy for details about local storage, optional sync, sharing, and deletion.

To report a problem or ask a question, open an issue at github.com/harryw1/nostalgos/issues (a free GitHub account is needed). Include your device model, OS version, NostalgOS version and the steps that lead to the problem. Issues are public: don’t post personal details, ROM files or backups.
